## Comment jouer

### Sélectionner les billes à bouger

1. Positionner le curseur sur la première bille à sélectionner
2. Glisser le curseur SANS lâcher le clique souris
3. Lâcher le clique pour valider les billes à sélectionnées

### Bouger les billes sélectionnées

1. Pointer le curseur dans la direction désiré
2. Cliquer pour valider le mouvement des billes, montrer par la prévisualisation

(Les mouvements interdits ne sont pas effectués)

### Annuler la séléction

Lors d'un sélection, ou avant de lâcher le clique. Il est possible de revenir à l'état de sélection des billes. Il faut cliquer droit.

### Revenir au menu principale en pleine partie

Appuyer sur `échap`.
